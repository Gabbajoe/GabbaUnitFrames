## 🚀 Ready to make it yours?

Install Gabba Unit Frames, then **left-click the minimap icon** or type **`/guf`** to open the settings. Drag the icon to put it where you like. 🧭

- 🐾 Party-pet scale from **100–200%**, with below, left or right positioning.
- 🔎 Player, target and own-pet text sizes from **8–16 px**.
- 🛡️ **1–8 raid groups per line**, horizontally or vertically, using Blizzard's **Separate Groups** layout.
- 💚 Layout changes made during combat apply after combat ends.
- 🧩 **Standalone:** no additional addons or external libraries required.
